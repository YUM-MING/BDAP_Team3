# BDAP_Team3
[BDAP_Team3] 재난 문자 데이터 분석: 기후 위기 체감도 시각화 
## 📅 분석 기간
> 2025.05.02 ~ 2025.06.20

## 📖 프로젝트 개요
### 분석 배경
>  최근 몇 년간 폭염, 미세먼지, 한파 등 기후 재난이 증가함에 따라, 행정안전부의 재난 문자 발송량도 함께 급증하고 있습니다. 그러나 국민이 이러한 재난을 실제로 어떻게 체감하고 있는지에 대한 분석은 여전히 부족한 실정입니다. 이에 본 프로젝트는 재난문자 통계, 기상 지표, 그리고 유튜브 댓글 데이터를 기반으로 기후재난의 객관적 빈도와 주관적 체감 간의 차이를 분석하고 시각화 자료를 제공하는 것을 목표로 하며, 이를 통해 보다 정교하고 감성 기반의 재난 대응 정책 수립에 기여하는 것을 목적으로 합니다.

### 문제 정의
> 1. 재난문자 발송 빈도는 실제 기상현상과 얼마나 일치하고 있는가?
> 2. 국민들은 이 기후 위기를 일상에서 체감하고 있는가?
> 3. 재난 문자 발송이 실제로 국민의 인식과 반응을 반영하고 있는가?

### 분석 목적
>1. 기후재난 발생의 객관적 지표
>2. 국민 체감의 주관적 지표 간의 차이 시각화
>3. 정책적 시사점과 지역별 전략 제안 및 도출

## 💿 데이터 설명
>  본 프로젝트는 재난문자와 기상 데이터를 기반으로 국민 체감도를 분석하기 위해 발송 시각, 유형, 지역 단위로 데이터를 정제하고, 날짜 및 지역 기준으로 통합하여 시계열 분석 및 시각화가 가능한 형태로 가공하였습니다. <br>

### 유튜브 댓글에서 수집한 재난 관련 텍스트 데이터
>  YouTube Data API v3을 활용해 재난 관련 유튜브 영상 수집 및 댓글 크롤링<br>
>  수집된 댓글에 대해 한국어 언어모델 KOTE를 적용해 감성 분석 진행<br>
>  이는 43가지 세부 감정 분류가 가능하며,  단순한 긍·부정 구분을 넘어 다양한 감정 반응 파악할 수 있음

## 🌟 **활용 방안**

| **재난 예측 및 예방**                | **감정 케어**                                         |
|-------------------------------------------------------------------|-------------------------------------------------------------------|
| ① 재난문자 발송 이력과 기후 데이터 분석하여, 특정 재난 유형의 발생 시기와 지역 **예측할 수 있는 모델** 기반 마련   | ① **감정 경향에 맞춘** 톤과 표현 방식을 설계하여 공감 중심의 재난문자 메시지 구성 가능 |
| ② 기후 요인과의 상관관계를 바탕으로 시기별 ·지역별 재난 **위험도를 시각화**하여 선제적 대응 가능     | ② 국민 정서를 반영한 **커뮤니케이션 전략**을 수립함으로써 **재난 상황에서도 효과적인 소통 가능** |
| ③ 발송 패턴 분석은 이상 기후에 대한 사전 경고 체계 설계와 향후 **자동화된 예측 시스템 구축**의 기반이 될 수 있음     | ③ 정서 기반의 대응 방식을 통해 **국민의 심리적 안정과 재난 정보에 대한 신뢰**를 높일 수 있음 |
